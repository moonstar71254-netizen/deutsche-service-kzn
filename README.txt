Инструкция по обновлению и публикации сайта Deutsche Service

1. Тексты, список услуг, график и контакты TG/WA:
   Откройте файл src/data/siteConfig.js и измените нужные строки в кавычках.

2. Фотографии:
   Положите свои фото в папку public/images/ и укажите пути (например, ./images/hero.jpg)
   в файле src/data/siteConfig.js.

3. Сборка и публикация на любой хостинг:
   Выполните команды `npm install` и `npm run build`.
   Готовая статика появится в папке dist/ — загрузите её содержимое на хостинг.
